# XrayESP-SeedTools

Fabric 1.21.11 client-side X-ray/ESP and known-seed analysis.

Commands: `/xray on|off|toggle`, `/esp on|off|toggle`, `/seedinfo <seed>`. `/seedinfo current` works only in an integrated singleplayer world.

The ESP only visualizes blocks already available in the client world. It does not recover hidden multiplayer server seeds.
